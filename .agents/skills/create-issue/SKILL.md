# Create an issue

Write for a time-poor technical reader unfamiliar with the implementation.
Lead with the problem, the value, and the proposed decision. Show a brief
before/after in code, or clearly labeled pseudocode. Explain module
responsibilities, interfaces, and how they interact. Include scope, the key
tradeoffs, and testable completion criteria. Link the relevant code.

Keep it punchy. Skip unexplained jargon and implementation archaeology.
